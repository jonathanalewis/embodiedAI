Galbot tests

Sends typed, everyday utterances through the real pipeline (this site's /api/turn → Claude) and checks the results. This page is separate from the app. A full run makes about 30 Claude calls, a few of them with web search (roughly $0.10–0.30 in API cost).

Pass/fail checks are automatic. Review means the automatic checks passed, but a person who knows the language should read the translation to confirm it is faithful.
